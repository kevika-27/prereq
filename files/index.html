NYU degree planner

A degree is not a list of courses. It is a tree of requirements where some branches are choices, and it only becomes a schedulable graph once those choices are made. This resolves the tree, then runs Kahn's algorithm over whatever falls out.

Requirements transcribed from the NYU Bulletin, the Courant course sequence pages, and the CAS Core Curriculum site. Verify against Albert before registering. Built as a data structures exercise: an AND/OR requirement tree resolved into a DAG, then Kahn topological sort, three-colour DFS cycle detection, longest-path dynamic programming, and greedy credit-budgeted scheduling, all written from scratch.
